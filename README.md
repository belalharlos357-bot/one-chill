One line of horror: the agent finishes the task before I ask, quotes a message I never sent, and keeps typing. (102 characters, limit 200.)

## Why this line

Horror works by escalation and an unresolved ending, not by gore. Three beats, each worse than the last: it finished early (uncanny), it quoted an unsent message (impossible), and it is still typing (it is not done with me). The last line lands the chill because it never explains itself — the reader fills in the rest.
